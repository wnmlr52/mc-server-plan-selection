## CPU怎么选：MC吃的是单核，不是核多

Minecraft对单核主频的依赖远大于核心数量，1.18之后的新版本把单核需求拉得更满。拿2.9GHz的老至强去开模组服，TPS掉到15不奇怪。选机器时先看单核能跑到多少GHz，再看核数和内存。

按第三方整理的机型分档：

- **i9-14900K / 14900KF**：6.0GHz，CPU-Z单核880–900分，1.20+大型模组整合包、50人起步群组服的首选
- **Ryzen 7950X / 9950X**：5.7GHz，Zen5架构，Linux下单核表现甚至反超i9，适合高版本插件和模组混开
- **R9 5900X**：4.8GHz，单核450–520分，中高版本模组服、小型群组的均衡档
- **Gold 6146**：4.2GHz，纯净插件服够用
- **Platinum 8275cl / 8259cl**：3.9GHz，多核强、单核弱，适合低版本模组或高版本纯净插件，有免费兑换套餐
- **E5 2666v3**：2.9GHz，单核最弱，只建议超低预算挂机服、低版本小型生存，同样有免费档

一句话的选型规则：1.18+模组服优先i9或Ryzen 7000系，低预算或老版本再考虑至强系列。版本越新、模组越重，单核越不能省。

## 面板服还是VPS：先看你要不要群组服和机器人

面板服和VPS的差别不在价格，在权限边界。面板档便宜、一键开服，MCSM面板里能选Paper、Spigot、Forge、Fabric，点几下就能启动。它不能做群组服，不能挂机器人框架，也不能用MCDR。需要这三样中的任何一样，只能上VPS。

VPS档自由度大，支持Linux和Windows，能挂Robot框架、组群组服、跑MCDR，代价是Java环境自己装、服务端jar自己传、启动脚本自己写。雨云官方论坛的两份教程立场正好相反：MCSM教程推荐面板，理由是便宜、小白友好；VPS教程推荐VPS，理由是扩展性强。这不是谁对谁错，是两类人的需求不同。没开过服、只和朋友联机，面板；有开服经验、要群组服或机器人，VPS。

计费模式也顺带说一句。官方教程推荐固定计费，全程火力全开；动态计费按CPU实际占用收“电量费”，闲置时段几乎不花钱，适合白天没人、晚上才热闹的私人小服。两种模式不冲突，看你的服什么时候有人。

## 开服最容易卡住的三件事

**1. NAT端口映射。** 公网IP实例直接用公网IP进游戏，不用映射。NAT实例要在面板里添加端口映射规则：外部端口一般随机生成，内部端口填实例上实际运行服务的端口号。MCJE走TCP，MCBE走UDP，Steam走UDP，Windows远程桌面用TCP或TCP+UDP。Java版默认端口是25565，资料原文有一处写成25665，按25565填。进不去游戏，先查内网端口对不对，再查外网端口有没有被占用。NAT端口不要用来建站。

**2. Java版本要和MC版本对上。** 1.8–1.12用Java 8，1.12–1.16用Java 11，1.16–1.20用Java 17或Java 21，1.21用Java 21。先确定要跑哪个版本，再装对应Java，不要盲目上最新版。VPS的Windows路线是：远程桌面连上后装Java，上传服务端，在服务端目录建一个Run.cmd，内容为`Java -jar 你的JAR核心.jar nogui`，双击启动。

**3. 首次启动要同意EULA。** 第一次启动会生成eula.txt，把里面改成同意后再启动一次，否则服务端会直接退出。MCSM面板的控制台能看到完整日志，Java版本不对、jar路径错了、端口被占，都会在里面报出来。

## 上线后的运维：备份、重启、白名单

MCSM面板能做的事比“一键开服”多：实例启停、崩溃自动拉起、实时控制台、在线改server.properties和插件配置、计划任务、CPU和内存监控、成员权限分配。真正影响长期体验的是三件事。

每日定时备份，备份world、world_nether、world_the_end和核心配置，保留最近7–14份，旧备份自动清理，防止磁盘爆。每天低峰定时重启，重启前5分钟和1分钟广播提醒，小服也能减少长期运行的资源碎片。公开服或有正版玩家，online-mode优先设true；设成false会出现OFFLINE/INSECURE MODE警告和冒名登录风险，私服也建议开白名单。面板本身要改默认密码，建议16位以上；“能改文件、能执行命令、能重启实例、能下载存档”是四类高风险权限，多人协作时尽量拆开授予。崩溃自动重启要配重启冷却时间和最大重启次数，否则会崩溃死循环刷日志。
